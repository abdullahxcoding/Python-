# Python Practice

A collection of beginner-to-intermediate Python programs written to practice core
programming concepts: conditionals, loops, pattern printing, object-oriented
programming, and a couple of small standalone problems.

Every file is self-contained and runs on its own with no dependencies beyond the
Python standard library.

## Contents

## Running a program

```bash
python decisions/ques1.py
```

Some programs read values with `input()`, so run them from a terminal rather
than from a non-interactive environment.
